# BookVerse

BookVerse is a clean and responsive online book discovery website built with **HTML, CSS, and JavaScript**. It allows users to explore books by category, search for books, and discover featured programming books using the Open Library API.


# Features

- Browse featured books on the Home page
-  Search books by title, author, or subject
-  Explore books by category
-  Fully responsive design
-  Dynamic book rendering using JavaScript
- Real-time data from the Open Library API

# API Used

Open Library Search API

```
https://openlibrary.org/search.json
```

Open Library Subjects API

```
https://openlibrary.org/subjects/{subject}.json
```

Book Covers API

```
https://covers.openlibrary.org/
```
